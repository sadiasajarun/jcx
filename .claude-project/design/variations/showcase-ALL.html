To record your choice

  1. Compare all three in both light and dark using the toggle above.
  2. Open any one full-page to scroll it properly — the strip and filters are live.
  3. Edit .claude-project/status/jcx/DESIGN_STATUS.md: set selected_variation: A|B|C and approved: true.
  4. Re-run /fullstack-pm jcx --phase P3-design --resume.

A Mix is allowed — record it as selected_variation: Mix and note which elements come from which variation.
